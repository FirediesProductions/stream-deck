# Macro X presets

Ready-made Macro Codes. Open any file, copy the text, and paste it into a Macro key's
code box - it just applies. Then change any path or text to yours.

These mirror the built-in presets in the plugin (grouped the same way), plus a few extras.
Every code here is verified against the real Macro X parser.

### Text & Type
- [Insert Date](insert-date.txt) - types today's date, always current
- [Timestamp](timestamp.txt) - date + time, for notes and logs
- [Paste Plain](paste-plain.txt) - paste without the formatting
- [Instant Reply](instant-reply.txt) - drop a saved message at the cursor
- [Paste My Email](paste-my-email.txt) - type your email (or any snippet you retype)

*Live tokens for `type`, expanded when you press: `{date}` `{time}` `{datetime}` `{isodate}` `{day}`.*

### Windows & Screens
- [Snip To Share](snip-to-share.txt) - the Windows region snipper
- [Screenshot To File](screenshot-to-file.txt) - full screen, saved to Pictures
- [Split Screen](split-screen.txt) - snap the window to the left half
- [Send To Other Screen](send-to-other-screen.txt) - throw it to the second monitor
- [Reopen Closed Tab](reopen-closed-tab.txt) - bring back the tab you just closed
- [Clipboard History](clipboard-history.txt) - everything you copied lately
- [Emoji Panel](emoji-panel.txt) - the Windows emoji picker
- [Lock The PC](lock-the-pc.txt) - lock your screen in one tap

### Media
- [Play / Pause](play-pause.txt) - pause whatever's playing
- [Next Track](next-track.txt) - skip the song
- [Mute Volume](mute-volume.txt) - silence everything

### Gaming
- [GL HF](gl-hf.txt) - types "gl hf" in match chat at one press
- [Clip The Last 30s](clip-the-last-30s.txt) - save the last 30s on any GPU (Game Bar)
- [Save That Clip](save-that-clip.txt) - the same via NVIDIA Instant Replay
- [Record Screen](record-screen.txt) - start / stop screen recording
- [Panic Button](panic-button.txt) - mute + hide everything

### AI - your own Claude
*(these run the Claude Code you install and sign into yourself - see the [reference](../macro-code-reference.md#claude--hand-the-job-to-ai))*
- [Fix My Writing](fix-my-writing.txt) - fix the text on your clipboard in place
- [Explain This](explain-this.txt) - plain-English explanation of anything you copied
- [Commit My Work](commit-my-work.txt) - stage + commit your repo with a real message

### More (community extras)
*Handy codes that aren't built into the plugin - paste them the same way.*
- [Start Streaming](start-streaming.txt) - open OBS and bring it up when ready
- [Did It Work?](did-it-work-devs.txt) - run a script, watch the tick or cross
- [Mute Discord](mute-discord.txt) - toggle your mic (set Ctrl+Shift+M as Discord's keybind first)
- [Start My Workday](start-my-workday.txt) - open your morning sites and folders
- [Launch My Game](launch-my-game.txt) - clear the desktop and open your game
- [Ready To Share Screen](ready-to-share-screen.txt) - hide the mess, show the window
